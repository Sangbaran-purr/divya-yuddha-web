An instrument, not a ceremony. Minting is owner-only — the chain enforces it.

Access Drop — AccessNFT.mint(to)

One soulbound Access NFT per wallet. Contract-enforced: a wallet that already holds one reverts AlreadyHolds — surfaced per-row, never halting a batch.

Wave Drop — WaveCardNFT.mint(to, cardId)

Wave cards only, grouped by faction (launch-88 cards are never individually minted and never appear here). Pick one card; drop it to one or many addresses.

Coin Drops — DYC.transfer(to, amount)

Plain ERC-20 transfers of DYC from your connected wallet — no approvals, no custody, no new contract. Amounts are in DYC (human units) and shown in raw wei at the confirm step. Every send is pre-simulated; a reverting row is surfaced and never halts the batch.

Approve Buyers — EIP-712 allowlist voucher

Read a wallet from your private registration Sheet, paste it here, and sign the presale voucher with this wallet (must be the sale's allowlistSigner). The signature proves nothing personal — the published allowlist.json holds only addresses + signatures. Publishing = committing that file. Batch supported; a rejected sign never halts the rest.

Purchase Registry — per-wallet chain truth

Loads the approved wallets from allowlist.json (add any extra wallets below), and for each reads its actual purchases from the sale's Purchased logs plus the live four-column state. Zero personal data — wallets and numbers only; match names in your private Sheet. Gated on this wallet == the sale's allowlistSigner, same as Approve Buyers. Read-only; nothing is signed or sent.

Configuration (this browser only)

Overrides admin-config.js for this browser via localStorage. Nothing is committed. Paste the G12 fresh contract addresses + the wave-card list, then Save. Clear to return to NOT CONFIGURED.

This page is unlinked from all navigation and non-indexed. It signs with the connected wallet only; it holds no key. Owner-only minting is enforced by the contracts (`onlyMinter` / `owner()`), not by this UI. Every send carries an explicit gas limit and a confirm step stating the count and destinations.
