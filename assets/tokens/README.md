duties**: it is the Rite Mark rendered on `rite.html` AND the intended NFT
metadata image wired at the Phase-A freeze. It is a byte-copy of
`assets/plates/rite_mark.webp` (derived from the accepted master
`docs/design/rite_mark_1024.png`); keep them identical, or re-copy after any
reroll.

⚠ ACCEPT-PENDING: the mark's blue-gem border awaits an owner word. Integrated
as-is; if a reroll lands it is a **single-file swap** (replace both
`assets/plates/rite_mark.*` and this copy).

the Torana — the same file `rite.html` serves in its TORANA presentation piece,
and from S-BUNDLE-1 also the face of the bundle tile on `store.html` (lazily, at
~340px, behind the same `.torana-ph` text placeholder on a 404). One file, two
pages; replace it in one place.
